# JOINS
This is a practice of JOINS functions using DATABRICKS for Bightlearn
This repository contains my solutions for the SQL Joins Exercise. The project focuses on understanding and applying the three most important SQL join operations:
INNER JOIN
LEFT JOIN
FULL OUTER JOIN
The exercise uses a streaming-service dataset consisting of five related tables. The goal is to practice combining data across tables, handling missing relationships, and understanding how different join types affect query results.
